# TATA Data Visualization Project – Forage Job Simulation

This project was completed as part of the "Data Visualization: Empowering Business with Effective Insights" simulation offered by the TATA Group via Forage.

## 🎯 Objective
To analyze an online retail dataset and generate business insights using Power BI and Tableau. The goal was to support data-driven decision-making through visual storytelling.

## 🛠️ Tools Used
- Microsoft Power BI
- Tableau
- Excel (for data preprocessing)

## 🧩 Key Tasks
- **Framing Business Questions:** Identified core business objectives and analysis focus.
- **Data Cleaning & Transformation:** Cleaned raw dataset for compatibility with BI tools.
- **Dashboard Creation:** Developed dynamic dashboards in both Power BI and Tableau.
- **Insight Generation:** Provided strategic insights based on sales patterns and KPIs.

## 📊 Outputs
- [x] Power BI Dashboard Report (`PowerBI_Dashboard_Report.docx`)
- [x] Tableau Dashboard Report (`Tableau_Dashboard_Report.docx`)
- [x] Online Retail Dataset (`Dataset/Online_Retail_Dataset.csv`)

## 📌 Key Insights
- Identified top-performing product categories.
- Analyzed customer purchase behavior by geography.
- Provided inventory and sales optimization suggestions.
